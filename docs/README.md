# Documentation

This folder contains all documentation for the Vader AI Agents system.

## Documentation Structure

### Agent Instructions
**Location:** `agents/` folder

Contains instruction files for each agent:
- **Agent Instructions:** Full instruction files for each agent (Crystal, Chloe, Preston, Winsley, Jude)
- **Cheat Sheets:** Quick reference guides for each agent (`_cheatsheet_*.md`)
- **Common Rules:** Shared rules and standards (`_common_rules.md`)
- **Examples:** Example handoff prompts (`_examples.md`)

See [`agents/README.md`](agents/README.md) for detailed agent documentation structure.

### Getting Started
- **`getting_started.md`** - How to start a chat with each agent
- **`common_workflows.md`** - Detailed workflows for common tasks

### System Documentation
- **`agent_system_overview.md`** - Complete system architecture and rules overview
- **`troubleshooting.md`** - Common issues and solutions

### Setup and Configuration
- **`AGENT_CHAT_SETUP.md`** - Setup instructions for agent chats
- **`AGENT_CONTEXT_REFRESH_PROMPT.md`** - Prompt template for refreshing agent context
- **`INSTRUCTION_FILE_STRATEGY.md`** - Strategy for accessing instruction files

### Testing and Validation
- **`JUDE_TEST_SETUP.md`** - Setup instructions for testing Jude validator

### Correction and Maintenance
- **`CRYSTAL_CORRECTION_PROMPT.md`** - Prompt template for correcting Crystal's responses

Historical analysis and review documents:
